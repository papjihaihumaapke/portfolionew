A "curtain-reveal" loading state that masks the UI until assets are ready. Includes a rhythmic bar animation to indicate system activity.

TUNING IN...
HTML Structure

     <div class="loader-bar"></div>...
  </div>

</div>
GSAP Exit Sequence 
// Triggered on window.load
masterTl
  .to(".loader-text", { y: -50, opacity: 0 }) 
  .to(".preloader", { 
      yPercent: -100, // Slide up like a curtain
      duration: 1.2, 
      ease: "power4.inOut" 
  });

04. Motion Component: Magnetic Button

A button that physically tracks the cursor movement before click to increase affordance.

Hover Me
GSAP Implementation 
// Javascript (GSAP)
magnetBtn.addEventListener('mousemove', (e) => {
  const bound = magnetBtn.getBoundingClientRect();
  const x = (e.clientX - centerX) * 0.3; // 0.3 = resistance
  const y = (e.clientY - centerY) * 0.3;
  
  gsap.to(magnetBtn, {
      x: x, 
      y: y, 
      duration: 0.3 
  });
});

07. Interaction: Horizontal Scroll

Converts vertical scroll energy into horizontal translation using Sticky Positioning and Vanilla JS math.

Vanilla JS Logic 
// 1. Calculate scroll percentage (0 to 1) based on section height
let percentage = (scrollY - sectionTop) / (sectionHeight - windowHeight);

// 2. Determine how much "overflow" width exists
const trackWidth = track.scrollWidth;
const maxScroll = trackWidth - window.innerWidth;

// 3. Translate track horizontally
const x = percentage * maxScroll;
track.style.transform = `translate3d(-${x}px, 0, 0)`;
